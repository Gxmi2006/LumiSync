## Release Naming

Use semantic versions:

- `v0.1.x`: original KONSL prototype lineage
- `v0.2.x`: LumiSync rebrand and generic window sync
- `v0.3.x`: monitor capture and profiles
- `v0.4.x`: edge sampling and gradients
- `v0.5.x`: plugin/API previews
- `v1.0.0`: stable config, signed builds, documented backend API

Release titles:

- `v0.2.0 "First Light"`
- `v0.3.0 "Window Glow"`
- `v0.4.0 "Edge Map"`
- `v0.5.0 "Plugin Pulse"`
