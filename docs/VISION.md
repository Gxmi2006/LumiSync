# Future Vision

LumiSync can become a lightweight SignalRGB alternative by staying focused on modular ambient automation instead of trying to duplicate every vendor-suite feature. The strongest path is an engine-first strategy:

- capture sources are plugins
- processing modes are plugins
- effects are stackable modules
- hardware backends are replaceable
- profiles are shareable files
- diagnostics are built into the culture of the project

## Community Ecosystem

The community can contribute:

- hardware backend plugins
- tested profiles for games and apps
- WLED/Hue/Nanoleaf mappings
- performance traces
- screenshots and demos
- hardware compatibility reports

## Sustainability Without Monetization

Keep the core free and MIT licensed. Sustainable growth can come from:

- excellent documentation
- contributor-friendly architecture
- reproducible builds
- hardware compatibility matrices
- GitHub Sponsors for maintainers
- optional community showcase pages

Avoid locking features behind payment or adding telemetry. Trust is a key differentiator.

## Plugin Marketplace Possibility

A future community registry could list plugins by type:

- capture source
- RGB backend
- effect
- profile pack
- integration

Start with a curated Markdown registry before building any marketplace infrastructure.

## Creator and Gamer Platform

LumiSync can grow beyond ambient keyboard sync into a creator utility platform:

- OBS scene-aware lighting
- Stream Deck controls
- Discord presence
- per-game lighting profiles
- home automation bridge
- local WebSocket status for overlays

The north star: premium-feeling open-source lighting automation that remains lightweight and understandable.
